# SoftGrowTech-Task2-Project2-File-organizer-tool
A Python File Organizer Tool that automatically sorts files into folders like Images, Documents, and Videos based on file types.
## File Organizer Tool
A simple Python project that automatically organizes files into different folders based on their file types.
## Features
Scan files in a selected folder
Separate images, documents, and videos
Automatically create folders
Move files into respective folders
Easy and beginner-friendly project
## Technologies Used
Python
os module
shutil module
## File Categories
Images → .jpg, .png, .jpeg, .gif
Documents → .pdf, .docx, .txt
Videos → .mp4, .mkv, .avi
How to Run
Open the project in VS Code
Run the Python file
Enter the folder path
Files will be organized automatically
Example
## Before organizing:
Downloads/
  photo.jpg
  notes.pdf
  video.mp4
## After organizing:
Downloads/
  Images/photo.jpg
  Documents/notes.pdf
  Videos/video.mp4
